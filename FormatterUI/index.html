WhatSock Apex4X Developer Tool

ARIA 4X Offline Formatter

Format and minify the framework, rebuild its bundle, and prepare the minified module path — all on your computer.

Local and offline: Nothing is uploaded. Python and Node.js are required, but you never need NPM, npx, or an internet connection.

1. Select operations

All four options are checked by default, reproducing the original Format.sh sequence.

Formatting steps, in execution order

Formats HTML, JavaScript, CSS, and JSON in the same Apex4X source locations as Format.sh.

Generates 4X/4X.js and the 4X/Min/ and 4X/Standard/Min/ module files, using the original command flags.

Compiles the existing BuildBundle.js with the repository's original rollup.config.js. Output: Bundle/4X.js.

Applies the exact module-folder change made by the original Save4X.py: /4X/Modules/ to /4X/Min/.

3. Backup and restore

Operations run in an isolated staging folder first. Only after all steps succeed are changed files applied to the repository. Each successful run saves copies of every replaced file in FormatterUI/backups/.

If something fails before the commit, the repository is left untouched. If a commit fails, previously applied files are rolled back.

Restore checks whether files changed after formatting. It refuses to overwrite newer work. This tool does not modify your original Format.sh or FormatInstall.sh.
